## What is unique to this file

Nothing. If a new section needs to live here, it should be one of:

- An implementation-aware note that does not belong in the bible, or
- A pointer to a chapter of the bible that is the canonical source.

When you find yourself wanting to add vision content to this file,
add it to the bible instead and link from here.
