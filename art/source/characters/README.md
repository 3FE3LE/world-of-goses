# Characters — source files

> Pixelorama sources for citizens, heroes, expedition members, and NPCs.

This folder holds the **editable** Pixelorama sources (`.pxo` or
`.pxm`). PNGs in `art/exports/characters/` are derived from these
sources and must not be edited by hand.

## Placeholder slice

The current vertical slice uses two placeholder PNGs generated by
`art/export_placeholder_art.js`:

| File                                                  | Size    | Purpose                                          |
| ----------------------------------------------------- | ------- | ------------------------------------------------ |
| `art/exports/characters/worker_placeholder.png`       | 64 × 96 | Single side-facing worker silhouette.            |

These placeholders are intentionally minimal. They exist to validate
that the art pipeline produces files at the right canvas size and
colour depth for the prototype. A real artist will replace them.

## Required sources for the next iteration

| Subject | File name           | Canvas  | Frames (current)                             |
| ------- | ------------------- | ------- | -------------------------------------------- |
| Worker  | `worker.pxo`        | 64 × 96 | `idle`, `walk`, `mine`, `carry`, `hurt` (4 each) |

When the worker is exported:

- Frame naming follows `art/exports/characters/worker_<state>_<frame>.png`.
- Sprite-sheet export uses `worker_<state>_sheet.png` with one row per
  frame at the canvas size.
- The default orientation is **side-facing**, looking to the right.
- The first frame of every state must be a complete silhouette so the
  final art can replace `worker_placeholder.png` without re-anchoring.

## Replacement workflow

1. Open `worker.pxo` in Pixelorama.
2. Edit frames.
3. **File → Export As…** PNG (or sprite-sheet PNG) into
   `art/exports/characters/`.
4. Re-import into `game/assets/characters/` through the Godot editor
   (or update `.import` metadata if you hand-edit it).
5. `SpriteFrames_Worker_<State>` resources are referenced from the
   `VisibleWorkerSlot` and `CityMacroView` scenes by name — no scene
   re-wiring should be needed when the placeholder PNG is replaced.
