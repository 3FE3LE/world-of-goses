# Buildings — source files

> Pixelorama sources for production buildings, monuments, and decorations.

This folder holds the **editable** Pixelorama sources (`.pxo` or
`.pxm`). PNGs in `art/exports/buildings/` are derived from these
sources and must not be edited by hand.

## Placeholder slice

The current vertical slice uses one placeholder PNG generated by
`art/export_placeholder_art.js`:

| File                                                | Size      | Purpose                                |
| --------------------------------------------------- | --------- | -------------------------------------- |
| `art/exports/buildings/mine_placeholder.png`        | 192 × 192 | Single-frame quarry placeholder.       |

The footprint is a 3 × 3 base unit (64 px), matching
`PresentationConstants.MacroPlotSize` in
`game/scripts/PresentationConstants.cs`.

## Required sources for the next iteration

| Subject       | File name              | Canvas   | Frames                       |
| ------------- | ---------------------- | -------- | ---------------------------- |
| Quarry (mine) | `quarry.pxo`           | 192 × 192 | `idle` (1), `active` (1)    |
| House         | `house.pxo`            | 128 × 128 | `idle` (1)                  |

The quarry placeholder uses a fixed view (front-on, no perspective).
When the real art replaces it, the slot in the macro view continues
to render at `MacroPlotSize × MacroPlotSize`.

## Replacement workflow

1. Open `quarry.pxo` in Pixelorama.
2. Edit frames at the canvas size listed above.
3. Export the frames as PNGs into `art/exports/buildings/`.
4. Import into `game/assets/buildings/` through the Godot editor.
5. The `MinePlot` placeholder references the texture by path
   (`res://assets/buildings/quarry_idle_0.png` once the real art lands).
