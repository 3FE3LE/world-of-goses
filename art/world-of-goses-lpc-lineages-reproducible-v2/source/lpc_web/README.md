# Selecciones futuras del generador web LPC

Sitio oficial:

```text
https://liberatedpixelcup.github.io/Universal-LPC-Spritesheet-Character-Generator/
```

La web permite exportar la selección al portapapeles como JSON e importarla después. Para cualquier personaje futuro construido directamente allí, guarda aquí:

```text
<personaje>.lpc.json
<personaje>.url.txt
<personaje>.credits.csv
```

Los 16 sprites actuales no dependen de una selección web completa: usan cuerpos LPC congelados en `source/lpc_bases/` y overlays originales definidos por `source/recipes/lineages.json`. Esta carpeta evita repetir ese error con personajes futuros.
